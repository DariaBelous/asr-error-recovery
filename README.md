# Восстановление голосового LLM-агента после ошибок распознавания речи
## о чем работа

Голосовой агент получает от распознавания речи текст с ошибками, проверяю, какие способы помогают агенту с этим справиться: показать ему несколько вариантов распознавания, подтверждать критичные данные, переспрашивать при низкой уверенности, плюс обучаю классификатор, который решает, когда переспрашивать

Агент и задачи взяты из бенчмарка tau-bench (домен airline). Сам бенчмарк текстовый, поэтому звук добавляется отдельно: реплика клиента озвучивается, проходит через телефонный фильтр и шум и распознается Whisper.

## структура

```
notebooks/   ноутбуки по порядку, запускаются в Google Colab
src/         код, который повторяется в нескольких ноутбуках
results/     таблицы и графики
```

## ноутбуки

| файл | что делает |
| --- | --- |
| 00_first_run_tau2.ipynb | один диалог tau-bench без голоса |
| 02_plohoy_telefon_asr.ipynb | синтез речи, шум, Whisper, N-best и уверенность

## как запустить

Открыть ноутбук в Colab, выбрать среду с GPU (T4) и запустить ячейки по порядку. Зависимости ставятся в первых ячейках. Для запуска на OpenAI нужен свой ключ в Colab Secrets под именем OPENAI_API_KEY

## данные и модели

tau-bench 2.0 (sierra-research/tau2-bench), SpokenWOZ, Whisper small.en, gTTS
